# Model artifact directories

These directories hold trained model artifacts produced by Phase 5 scripts.

- `backbones/`: Saved backbone weights or backbone-specific artifacts. (INPUT_REQUIRED when using pretrained backbones.)
- `classifiers/`: Saved classifier heads/weights. (INPUT_REQUIRED when checkpoints are exported.)
- `ensembles/`: Ensemble member configurations and combination metadata. (INPUT_REQUIRED when ensembling.)
- `layers/`: Fine-tuned layer checkpoints or feature extractors. (INPUT_REQUIRED as needed.)
- `losses/`: Loss weight histories or curve artifacts (optional).
- `multitask/`: Multi-task model artifacts and task heads. (INPUT_REQUIRED when multitask training runs.)
- `segmentation/`: Segmentation model checkpoints and masks. (INPUT_REQUIRED when segmentation is used.)
- `benchmarks/`: Benchmark reports (JSON) from `ml/scripts/benchmark_model.py`.
- `calibration/`: Calibration artifacts and reports (generated by `ml/scripts/calibrate.py`).
- `checkpoints/`: Training checkpoints (best.pt, last.pt, metadata) from the trainer. (INPUT_REQUIRED at runtime.)
- `data/`: Synthetic/test fixtures used only in development. Never contains PHI. (INPUT_REQUIRED when generating fixtures.)
- `datasets/`: Dataset-level model-specific splits or cached arrays (optional). Never contains PHI.
- `evaluation/`: Evaluation reports (internal/external/subgroup).
- `experiments/`: Experiment logs (JSONL) from `ml/scripts/train.py`.
- `explainability/`: Explanations and heatmaps from `ml/scripts/generate_explanations.py`.
- `export/`: Packaged models for handoff to the model service.
- `feature_engineering/`: Feature pipelines (optional; lazy to avoid heavy deps).
- `inference/`: Inference-time caches (optional; no patient data).
- `metrics/`: Aggregated metrics and summary tables (JSON/CSV, optional).
- `optimization/`: Hyperparameter search artifacts (optional).
- `outputs/`: Directory containing `metrics/`, `plots/`, `predictions/`, `reports/` generated by evaluation/training scripts.

No patient data or weights are committed to the repository. Fill paths and artifacts only when available (INPUT_REQUIRED where stated).
