# Model artifact directories (backbones)

This directory holds trained backbone weights or backbone-specific artifacts.

**Guidelines:**
- Do not commit patient data, PHI, or pretrained weights unless they are explicitly approved and licence-compliant.
- Paths and filenames are `INPUT_REQUIRED` when using pretrained backbones.
- Artifacts are generated by training or export scripts; the repository only provides this placeholder.

Expected artefacts (optional): `{backbone}_imagenet_init.pt`, `{backbone}_finetuned.pt`, metadata JSON files.
