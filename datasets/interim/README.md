# `interim/` — intermediate artifacts

Holds data produced between raw ingestion and final processing: the normalised
manifest, validation/cleaning/statistics reports and exclude lists. Contents are
generated by the `ml/scripts/*` pipeline and are not committed to version
control.

## Typical contents

| File | Produced by | Description |
| --- | --- | --- |
| `manifest.csv` | `ingest_dataset.py` | Canonical, cleaned manifest. |
| `manifest.validation.json` | `validate_dataset.py` | Validation report. |
| `manifest.cleaning.json` | `clean_dataset.py` | Duplicate/corruption/outlier report. |
| `manifest.exclude.csv` | `clean_dataset.py` | Record ids to exclude and reasons. |
| `dataset.statistics.json` | `calculate_statistics.py` | Class/image/demographic stats. |

Interim files may contain pseudonymous keys only. They are safe to regenerate
from `raw/` and the configuration, so they are disposable.
